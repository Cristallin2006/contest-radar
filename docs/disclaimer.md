# 数据与时间免责声明

- 生效日期：2026-11-23
- 适用范围：竞赛雷达网页、公开 API、ICS 日历、竞赛馆、线路图、卡片列表

## 1. 信息不是官方公告

竞赛雷达是公开竞赛信息的聚合与整理工具，不是任何赛事的主办方、报名平台或官方发布渠道。

站内展示的赛事名称、主办方、类别、方向、地区、报名时间、比赛时间、截止时间、费用、资格、奖项、阶段、官网链接等，均来自公开来源或人工整理，**可能存在缺失、滞后、重复、误判或已经变更**。

## 2. 时间与地区尤其需要核实

- 部分日期来自主办方公告，部分日期是预计、暂定或根据往届推断。
- 页面上的“预计”“暂定”“待定”标记表示该时间并非最终确认。
- 同一赛事可能同时存在线上、线下、分赛区、省赛、国赛等多个阶段。
- 地区的“国内 / 国际”只是聚合标签，不代表参赛资格或赛事归属的官方定义。
- 时区默认按北京时间（Asia/Shanghai）展示；跨时区赛事可能因时差产生日期差异。
- ICS 日历中的提醒仅作辅助，不能替代主办方通知。

**请务必以主办方官网、官方报名系统、官方公众号或组委会通知为准，并自行判断和核实。**

## 3. 数据更新与审核

- 采集器会定期抓取公开来源，但来源更新频率、接口稳定性和页面结构都会影响结果。
- 新采集内容默认进入待审核区，审核通过后才可能公开。
- 公开数据会保留最后核实时间和来源；没有核实时间不代表内容已过期，也不代表内容正确。
- 分类算法是辅助工具，方向和内容类型可能存在误判；管理员可手动修正。

## 4. 不构成建议

站内排序、筛选、推荐、匹配评分、收藏和日历提醒均不构成报名建议、参赛建议、投资建议或任何形式的保证。

## 5. 纠错

发现错误、过期信息或未收录赛事，可通过项目仓库提交 Issue，或在投稿功能上线后提交。提交前请尽量附上主办方官方链接和截图。
