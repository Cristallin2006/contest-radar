# 竞赛情报与公共赛历系统（匿名版）需求文档

- 版本：v0.2-anon
- 日期：2026-11-23
- 关系：基于 v0.1《竞赛情报与个人赛程系统需求文档》做匿名化删减；v0.1 原文保留，作为未来恢复账号/队伍/履历功能时的参考。
- 定位：**公开可访问的竞赛情报与赛历站**。不做账号、队伍、服务端个人赛程、服务端履历。

---

## 1. 背景与目标

### 1.1 项目性质

个人开发和维护，部署到公网，主要给一支战队及少量朋友使用。用户规模按 10–100 人设计，但**不要求登录**，不积累用户个人信息。

### 1.2 要解决的问题

| 问题 | 对应模块 |
|---|---|
| 不知道有哪些比赛 | 赛事库 + 公开列表 |
| 不知道比赛适不适合自己 | 浏览器本地画像 + 前端匹配评分 |
| 不知道什么时候报名、容易错过 | 公共 ICS + 手机日历提醒 |
| 想把关注的比赛放进自己的日历 | 本地收藏 + ICS 导出/订阅 |
| 想给队友分享赛历 | 公开链接 + 公共 ICS |

### 1.3 目标

1. 打开网页就能看到未来 3 个月的比赛，可按地区、类别、方向、赛制、线上/线下、时间筛选。
2. 每场比赛有系列、届次、阶段、报名截止、参赛条件、官网链接、最后核实时间。
3. 任何人不登录都能浏览、搜索、复制链接、导出 ICS。
4. 个人收藏、隐藏、本地画像、匹配评分只存在浏览器 `localStorage`，不上传服务器。
5. 管理员用一个令牌维护赛事库、审核采集结果，不需要用户系统。

### 1.4 明确不做

- 不做注册、登录、邀请码、角色、密码、TOTP、OAuth。
- 不做队伍、组队、找队友、队友关注可见性。
- 不做服务端个人赛程、服务端“已报名/已参赛”状态。
- 不做服务端履历、证书附件、writeup 托管。
- 不做用户上传文件、头像、评论、私信。
- 不做邮件提醒（v1）；提醒依赖 ICS `VALARM` + 手机日历。
- 不做原生 App；手机端使用响应式网页 + 日历订阅。
- 不做全文转载，只存结构化信息和原文链接。

## 2. 用户与角色

| 角色 | 说明 | 权限 |
|---|---|---|
| 访客 | 所有访问者，无需登录 | 浏览、搜索、筛选、看详情、导出/订阅公共 ICS、本地收藏、本地画像、本地匹配 |
| 管理员 | 项目作者或持有管理员令牌的人 | 访客权限 + 赛事增删改、审核采集结果、标签管理、查看审计/任务状态 |

**管理员不是账号体系**：没有用户名/密码/会话；使用环境变量中的 `ADMIN_TOKEN`，通过 `X-Admin-Token` 请求头调用管理接口。管理页面只把令牌存在浏览器 `sessionStorage`，关闭标签页即失效。可选：Nginx 对 `/admin` 和管理 API 做 IP 白名单/Basic Auth。

## 3. 功能需求

优先级：P0 = MVP 必做；P1 = 第二版；P2 = 以后考虑。

### 3.1 赛事库（EVT）

数据结构：**赛事系列 → 届次 → 阶段**。例如“强网杯”是系列，“2026 强网杯”是届次，“线上初赛”是阶段。

| 编号 | 需求 | 优先级 |
|---|---|---|
| EVT-01 | 赛事系列、届次、阶段三层模型；届次可没有系列（一次性比赛） | P0 |
| EVT-02 | 公开列表：默认显示未来 3 个月未结束的届次，按时间排序 | P0 |
| EVT-03 | 筛选：地区（国内/国外）、类别（CTF/黑客松/数据/数模/学科）、方向标签、赛制、线上/线下、状态、时间范围、是否白名单 | P0 |
| EVT-04 | 关键词搜索：名称、简称、主办方、标签 | P0 |
| EVT-05 | 详情页：基本信息、各阶段时间、参赛条件、奖项、官网/原文链接、最后核实时间、往届链接 | P0 |
| EVT-06 | 管理员新增、修改、归档赛事；所有时间按 Asia/Shanghai 录入，内部存 UTC | P0 |
| EVT-07 | 每条赛事记录修改历史（何时、改了哪些字段、操作者令牌标签） | P0 |
| EVT-08 | 自动同步 CTFtime / 攻防世界 / 好靶场 / CTFHub / Devpost / DrivenData / COMAP / 我爱竞赛网，进入“待审核”区 | P0 |
| EVT-09 | 管理员审核采集结果：采纳、合并到已有届次、忽略 | P0 |
| EVT-10 | 标签管理：方向、赛制；可由管理员扩展 | P0 |
| EVT-11 | 公开变更记录：最近新增/时间变更/取消的赛事，供访客查看（不做定向通知） | P1 |
| EVT-12 | 匿名线索提交：粘贴链接 + 备注；带限流/验证码，防垃圾；管理员审核 | P2 |
| EVT-13 | LLM 辅助录入：粘贴公告文本自动抽取字段，人工确认后保存 | P2 |
| EVT-14 | 监控指定官网/公告页内容变化，提示管理员核对 | P2 |
| EVT-15 | 时间语义：已确认 / 暂定 / 待定；只有截止时间的阶段只存截止时间，不能用“开始=结束”伪装；待定/暂定不生成精确提醒 | P0 |
**赛事字段**

- 系列：名称、简称、主办方、类别、官网、是否白名单、简介、地区。
- 届次：年份/届数、标题、生命周期（正常/延期/取消/结束）、报名组织方式（个人/队长/学校）、提交渠道（网站/邮箱/其他）、报名链接、费用、队伍人数上下限、资格要求、奖项说明、方向标签、赛制标签、难度 1–5、来源、最后核实时间、发布状态（草稿/待审核/已发布/归档）。
- 状态（报名中/进行中/已结束等）由阶段时间和生命周期推导，允许多个阶段状态并存；“归档”不等于“取消”。
- 阶段：名称、类型（报名/资格审核/初赛/复赛/决赛/材料提交/其他）、开始时间、结束时间、截止时间、时间状态（已确认/暂定/待定）、全天标记、线上/线下/混合、地点、备注。只有截止时间的阶段只填截止时间，不用开始=结束；待定/暂定不生成精确提醒。
- 标签取值：
  - 方向：Web、Pwn、Reverse、Crypto、Misc、Forensics、Mobile、IoT、AI 安全、区块链、算法、开发。
  - 赛制：Jeopardy、AWD、AWD Plus、渗透实战、KoH、攻防混合、ACM、OI、作品赛、答辩赛。

### 3.2 公开访问（PUB）

| 编号 | 需求 | 优先级 |
|---|---|---|
| PUB-01 | 无需登录即可访问列表、详情、搜索、筛选、公共 ICS | P0 |
| PUB-02 | 默认地区为“国内”；可切换“国外”；地区内再按类别/方向/赛制筛选 | P0 |
| PUB-03 | 分享链接可复现当前筛选（URL 参数） | P0 |
| PUB-04 | 基础 SEO：标题、描述、Open Graph；列表页可被搜索引擎抓取 | P1 |
| PUB-05 | 公开变更记录页 `/changes` | P1 |
| PUB-06 | 站点公告/免责声明：日期以官网为准、只做聚合 | P0 |

### 3.3 本地个人化（PER）

所有个人数据只存在浏览器，不上传服务端。

| 编号 | 需求 | 优先级 |
|---|---|---|
| PER-01 | 收藏/隐藏赛事；刷新页面后保留（localStorage） | P0 |
| PER-02 | “我的赛程”视图：仅显示收藏届次的所有阶段 | P0 |
| PER-03 | 导出选中赛事为 `.ics`（浏览器生成，静态文件） | P0 |
| PER-04 | 本地画像：学历阶段、年级、擅长方向及自评 1–5、目标（练手/拿奖/白名单/奖金/求职）、只参加线上、不可用时间段 | P1 |
| PER-05 | 前端匹配评分：根据画像和赛事标签给出分数 + 理由；硬条件不满足标灰，不隐藏 | P1 |
| PER-06 | 本地画像/收藏/隐藏可导出/导入 JSON，便于换浏览器或备份 | P1 |
| PER-07 | 清除本地数据按钮 | P0 |
| PER-08 | 跨设备同步 | 不做 |

**说明**：本地画像/匹配不落库，不参与公共排序；不同浏览器/设备各自独立。

### 3.4 日历与提醒（CAL）

| 编号 | 需求 | 优先级 |
|---|---|---|
| CAL-01 | 公共 ICS：全部赛事、按地区、按类别；可被手机日历订阅 | P0 |
| CAL-02 | 每个阶段生成一个 VEVENT；稳定 UID、SEQUENCE/LAST-MODIFIED；只有截止点的阶段只用 DTSTART；报名截止加 `VALARM`（提前 1/3/7 天可配） | P0 |
| CAL-07 | 取消/延期保留 UID 并标记取消；说明不同手机/云日历刷新行为不一致，不承诺所有客户端即时响铃 | P1 |
| CAL-03 | 收藏赛事的静态 `.ics` 导出（浏览器生成） | P0 |
| CAL-04 | ICS 响应缓存 15 分钟；支持 ETag/Last-Modified | P1 |
| CAL-05 | 可选邮件提醒：用户提交邮箱 + 选择赛事，生成只读订阅令牌；明确告知会存邮箱 | P2 |
| CAL-06 | Telegram/QQ/企业微信推送 | 不做（v1） |

**说明**：v1 不存邮箱、不发邮件；提醒完全依赖 ICS + 手机日历。CAL-05 如果要做，就不再是“纯匿名”，需要重新评估隐私与运维成本。

### 3.5 管理后台（ADM）

| 编号 | 需求 | 优先级 |
|---|---|---|
| ADM-01 | 管理员令牌认证（`X-Admin-Token`），无账号/会话 | P0 |
| ADM-02 | 待审核区：采集结果、重复合并、采纳/忽略 | P0 |
| ADM-03 | 赛事 CRUD、阶段编辑、标签管理、发布/归档 | P0 |
| ADM-04 | 数据源状态：最近运行时间、结果、错误、条数；手动触发采集 | P0 |
| ADM-05 | 修改历史/审计日志：操作者令牌标签、时间、字段差异、IP | P0 |
| ADM-06 | 手动触发 SQLite 备份，查看备份记录 | P1 |
| ADM-07 | 系统状态：健康检查、数据库大小、磁盘、采集任务 | P1 |
| ADM-08 | 用户管理、邀请码、角色 | 不做 |

### 3.6 赛事数据质量

| 编号 | 需求 | 优先级 |
|---|---|---|
| DQ-01 | 每条届次存来源、原文链接、最后核实时间 | P0 |
| DQ-02 | 日期置信度：官方 / 预计 / 待核对 | P0 |
| DQ-03 | 采集结果默认进待审核，管理员确认后才公开（可信源可配置直发） | P0 |
| DQ-04 | 同一赛事跨源合并：别名 + 年份 + 主办方；避免重复 | P0 |
| DQ-05 | 取消/延期/截止时间变更写入修改历史，并在公开变更页展示 | P1 |

## 4. 非功能需求

### 4.1 性能与容量

- 用户量 ≤ 100，公开读为主，写操作仅管理员。
- 单台 1C1G–2C2G 可运行；当前 4C4G 共享服务器绰绰有余。
- 列表首屏 < 1 秒（国内网络，CDN/缓存后）。
- 公共 ICS 可缓存 15 分钟。

### 4.2 安全

- 全站 HTTPS，HSTS；管理入口可选 IP 白名单/VPN。
- 管理员令牌强随机（≥32 字节），只放环境变量；日志不打印令牌。
- 管理写接口校验 `Origin`，使用自定义头；不做 Cookie 会话。
- 公开读接口限流（Nginx `limit_req`），防爬/防打。
- 采集/线索 URL 做 SSRF 防护：只允许 http/https，拒绝内网/回环/云元数据，限制重定向和响应体大小。
- 输出 HTML 做转义；CSP、`X-Content-Type-Options`、`Referrer-Policy`。
- 不存用户 PII；没有密码、邮箱、证书附件。
- 备份加密，异地保存；定期恢复演练。

### 4.3 可用性

- 桌面和手机浏览器可用；中文界面；时间统一北京时间展示。
- 无登录门槛；本地数据丢失可重新收藏/导入。
- 服务端故障时，已导出的 ICS 仍可用。

### 4.4 合规

- 只存结构化信息和原文链接，不全文转载。
- 尊重来源站点 ToS/robots；采集频率合理。
- CTFtime API 有用途限制，不假设可以做一个 CTFtime 克隆；只存必要字段并链接回原文，必要时联系对方确认。
- 大陆服务器需 ICP 备案；海外/香港免备案但国内访问慢。
- 无用户个人信息，隐私合规压力小；若未来加邮箱订阅，需单独告知和删除机制。

## 6. 待定问题

1. 站点是否完全公开可搜索，还是只发链接、不加 SEO？公开便于分享，但会增加爬取和攻击面。
2. 管理入口是否只允许 VPN/IP 白名单，还是公网 + 强令牌即可？
3. 服务器放大陆（备案）还是香港/海外？当前海外 VPS 可先跑。
4. 是否需要“匿名线索提交”？如果需要，必须加验证码/限流，否则垃圾线索会很多。
5. 以后是否恢复账号/队伍/履历？v0.2 不预留 `team_id` 半成品字段；如果要做，按 v0.1 重新设计权限/唯一键/缓存/任务隔离，或独立部署。
6. 是否需要邮件提醒？如果坚持纯匿名，v1 不做；如果做，按 CAL-05 的轻量令牌方案单独评估。

## 7. 验收清单（MVP）

- [ ] 访客打开首页默认看到“国内”未来 3 个月赛事。
- [ ] 可按类别、方向、赛制、线上/线下、状态、时间筛选。
- [ ] 详情页能看到系列/届次/阶段、报名截止、官网、最后核实时间。
- [ ] 公共 ICS 能被 Google Calendar / 手机日历订阅，报名截止有 VALARM；改期/取消保留 UID。
- [ ] “暂定/待定”赛事明确标注，不生成假日期和精确提醒。
- [ ] 收藏比赛后刷新页面仍在；可导出选中赛事的 `.ics`。
- [ ] 管理员用令牌新增/修改/归档赛事，修改有历史。
- [ ] 采集结果进入待审核区，管理员采纳后公开。
- [ ] 数据源状态页能看到最近运行时间和错误。
- [ ] SQLite 每日备份，能恢复。
- [ ] 无登录、无用户表、无队伍表、无服务端履历。
