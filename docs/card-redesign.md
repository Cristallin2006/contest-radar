# 卡片 v2：日期票根

- 设计日期：2026-11-24
- 范围：`/list` 的赛事卡片

## 设计

- 左侧日期票根：月.日、星期、剩余天数
- 移除卡片顶部的类别 / 方向 / 状态 / 置信度胶囊
- 标题清掉采集来源前缀，例如「【榜单赛事，程序设计挑战赛】」
- 摘要只保留清理后的内容；来源元数据不显示
- 截止日期只在票根出现一次
- 类别只保留一个低饱和圆点
- 收藏和官网收进右侧窄栏
- 临近截止的卡片使用砖红票根；普通卡保持纸色
