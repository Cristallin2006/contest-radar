文档

数据口径、免责声明和公开 API。先看说明，再使用数据。

时间、地区、赛制、费用等信息不保证准确或实时。

本站是公开信息聚合工具，不是主办方，也不是报名平台。部分日期为预计/暂定，部分赛事存在线上/线下、分赛区、跨时区等复杂情况。请务必以主办方官网和报名系统为准，并自行判断核实。

数据口径

  • 赛事名称、主办方、类别、方向、地区、时间、费用、资格等来自公开来源或人工整理。
  • “预计”“暂定”“待定”表示时间尚未最终确认；不能当作官方日期。
  • 国内/国际只是聚合标签，不代表参赛资格或赛事归属的官方定义。
  • 时间默认使用北京时间（Asia/Shanghai）；跨时区赛事可能产生日期差异。
  • ICS 提醒只作辅助，不能替代主办方通知。
  • 公开列表只展示正式竞赛；志愿者招募、活动、课程等会被过滤或隐藏。

完整说明：数据与时间免责声明

更新与审核

采集器默认每 6 小时自动抓取一次公开来源，并把新内容送入待审核区；新赛事和时间变更不会自动越过审核直接公开。公开记录会显示来源和最后核实时间；没有核实时间不代表内容已过期，也不代表内容正确。

分类（类别 / 方向 / 内容类型）为辅助信息，可能存在误判，管理员可手动修正。

公开 API v1

Base URL：https://contest.07212006.xyz/api/v1

公开接口只读，不需要登录；只返回已发布且 content_type=competition 的赛事。

方法路径说明
GET/editions赛事列表，支持筛选、搜索、分页
GET/editions/:id单个赛事详情（含阶段、标签、来源）
GET/taxonomy类别、方向、内容类型、阶段等字典
GET/stats公开赛事统计
GET/changes公开变更记录
GET/health健康检查与 schema 版本
GET/ical/all.ics全部公开赛事的 ICS
GET/ical/region/:region.icscn / intl
GET/ical/category/:category.ics按类别导出

列表查询参数

参数说明
regioncn / intl
categoryctf / hackathon / datamodel / mathmodel / academic / other
field方向，可逗号分隔，如 software,electronics
tech=1只看技术向（网络安全 / 计算机 / 数据 / 数学 / 电子 / 工程）
statusopen / closing / upcoming / ongoing / closed / ended / unknown / cancelled / postponed
q搜索标题 / 系列 / 主办方
from, toYYYY-MM-DD 日期范围
include_unknown=1包含日期未知的赛事
all_dates=1不限制默认约 90 天窗口
sort如 deadline / updated
page页码，默认 1
size每页数量，默认 20，最大 100

请求示例

# 国内数学建模
curl 'https://contest.07212006.xyz/api/v1/editions?region=cn&category=mathmodel&all_dates=1&size=5'

# 只看技术向
curl 'https://contest.07212006.xyz/api/v1/editions?tech=1&all_dates=1&size=10'

# 单个赛事
curl 'https://contest.07212006.xyz/api/v1/editions/232'

列表响应包含 items、page、size、total、pages 和 stats。分页时逐页请求。

ICS 日历

阶段级 UID 稳定；只有确认的截止时间才带精确 VALARM。预计/待定日期不会生成精确提醒，默认时区为 Asia/Shanghai。

订阅入口：全部赛事 ICS。也可以使用分类或地区路径。

错误与使用限制

错误格式：{"code":"EDITION_NOT_FOUND","message":"赛事不存在或未发布"}

  • 公开 JSON 默认缓存 60 秒，分类字典 1 小时，ICS 15 分钟。
  • 支持 If-None-Match / 304，请优先利用缓存。
  • 请勿高频轮询；公开 API 不是官方报名数据源。
  • 接口可能变更，变更会尽量记录在公开变更页。

纠错与反馈

发现日期、地区、主办方、分类或链接错误，请附上主办方官方链接提交 Issue。涉及公开留言/用户投稿的能力会在后续阶段单独上线。
