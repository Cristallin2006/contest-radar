# 赛线 OS · Arch Rice

## 视觉主题与氛围

读取为：模拟 Arch 电脑的竞赛 OS，面向开发者与 CTF 用户，使用 Hyprland、Waybar、Rofi 的系统交互语言。视觉冒险度 8/10，动效 5/10，桌面信息密度 3/10，应用内部密度 7/10。

已明确否定传统三栏工作站，不再比较或混搭后台布局。Win32、GNOME 与 KDE 均不采用；执行方向为用户确认的虚拟 Arch 电脑。

功能契约：首屏必须是可感知的桌面；应用按需成为独立窗口；关闭全部应用后回到桌面；每个虚拟工作区拥有自己的窗口；终端能启动应用并共享赛事状态；平铺只是可切换的窗口模式。

记忆点：在山脊壁纸与桌面小组件组成的真实桌面上，终端和赛事应用以浮动窗口打开，拖到边缘吸附，切换平铺后由窗口管理器自动重排。

## 色板与角色

提供三套可随时切换、持久化保存的完整主题，系统窗口与终端共用主题选择，但使用不同色彩角色。默认壁纸为 Kali 2026 官方 Kali Net；山脊壁纸仍保留在壁纸库中，可随时切换，不随主题替换。

- **Wallhaven / Omarchy（默认）**：桌面 `#0b0924`，应用窗口为中性炭灰半透明表面，正文 `#f0f0f2` / 85%。系统强调色使用上游色板中的雾玫瑰 `#c593b5`，焦点边框使用 `#76586d`，选中底透明度控制在 9–10%，不再让应用整体呈现紫色。终端仍严格采用 Wallhaven Kitty 的背景 `#1a1b26`、前景 `#a9b1d6`、选区 `#292e42` / `#c0caf5` 与完整 ANSI 色值。本地 JetBrains Mono 用于英文和数字，中文仍使用系统字体。
- **Afterglow**：桌面 `#202020`，窗口为中性炭灰半透明表面，正文 `#f5f5f5` / 85%，焦点使用克制的 ANSI 蓝 `#6c99ba`。终端严格采用背景 `#202020`、前景 `#d0d0d0`、选区 `#303030`，错误 `#ac4142`、成功 `#7e8d50`、警告 `#e5b566`、信息 `#6c99ba`。
- **Atelier Sulphurpool**：桌面 `#202745`，窗口为低饱和蓝紫灰，正文 `#f4f7ff` / 85%，焦点使用 `#3d8ed0`。终端严格采用背景 `#202745`、前景 `#969cb3`、选区 `#5e6686`，完整 ANSI 色值来自上游同名配置。

主题色只负责焦点、选中与语义，不给整个界面套绿色或其他单色滤镜。窗口正文为保证中文阅读使用较亮中性色，终端正文则忠实于 Kitty 主题，二者不混用 token。无霓虹光晕和高饱和渐变。

## 排版规则

中文正文使用系统无衬线；Wallhaven 的英文、数字和终端使用本地 JetBrains Mono，另外两套主题使用 Cascadia Code、SFMono-Regular、Consolas。正文 14px，辅助信息 12px，桌面时钟使用等宽数字而非营销标题。无斜体、无负字距。

## 组件样式

- Waybar：三套主题统一使用 46px 三段分岛栏，左侧系统入口与数字工作区、中间时间、右侧平铺与通知。分隔区域露出原壁纸，不添加媒体、天气或虚假系统监控，也没有永久搜索框。
- 桌面：本地 SVG 山脊壁纸、Papirus 应用图标、时钟和真实下一节点小组件，不再给图标套自制彩色方块；组件可关闭并能从 Rofi 恢复，状态持久化。
- 状态：临近节点使用 `D-DAY / D-1 / D-3`，普通状态直接显示“报名中 / 预告”，不重复圆点。
- 窗口：三套主题统一为默认浮动、8px 圆角、1px 主题活动边框、30px 紧凑标题栏与 94% 非活动窗口透明度。窗口背景和内容表面分别控制透明度，CSS 14px 背景模糊让桌面与窗口形成真实层级。取消双层描边和内高光，只保留中性阴影。允许左右部分越界和底部下沉，至少保留 96px 标题区域或 40px 标题栏用于拖回。
- 平铺：用户主动切换；1 个全屏、2 个左右、3 个主从、4 个及以上自动网格，退出后恢复浮动位置；Anime.js 只负责 280ms 可中断位置补偿与轻微透明度过渡，不缩放窗口内容；鼠标打开应用使用 180ms 上移淡入。
- Rofi：Ctrl/Cmd+K 按需打开，搜索应用、运行窗口、系统命令和赛事；参考 adi1090x/rofi 的无外框浮层，不使用多层科技描边。
- 终端：独立浮动应用，可启动其他应用、筛选、收藏、导出、切换工作区和平铺。取消会话工具条、快捷命令卡片和独立输入底栏，输出与 shell 提示符位于同一滚动文本流；首次挂载显示 `fastfetch` 式纯文本系统信息，支持 `fetch`、`theme`、历史命令和真实的 `zsh` 式提示符。
- 赛事：单击打开独立详情窗口，外层只保留名称、类型、下一节点与状态。

## 布局原则

桌面不是业务面板容器。窗口层与桌面图标、小组件共享空间；默认不自动打开赛事。移动端退化为全屏应用和系统入口，不缩小桌面窗口。

## 深度层级

普通窗口通过暗色半透明材质、清晰边框和两层中性阴影浮在壁纸上。只有窗口、Rofi、通知使用 backdrop-filter；业务内容区保持平面，以低透明中性表面和细分隔线保证可读性。

## Do's / Don'ts

- 工作区是虚拟桌面，不是业务导航标签。
- 新功能注册成应用和 Rofi 命令，不增加后台导航页。
- 不设置开始菜单、底部任务栏、永久三栏或固定搜索框。
- 不伪造 CPU、内存、在线用户和同步状态。
- 窗口关闭后必须真正回到桌面，启动层退出后必须从 DOM 移除。

## 响应式

桌面保留完整 OS 交互；小于 760px 时窗口全屏，桌面快捷方式收纳为应用列表，详情和终端同样全屏。所有核心动作均可通过触控完成。

## Motion 哲学

窗口拖动 1:1 跟手并捕获指针，不使用脚本动画抢控制；吸附和平铺只在释放后重排。Rofi 等键盘高频入口无入场动画。通知和 Toast 使用 160–220ms transform/opacity。支持 reduced-motion。

## DNA 注入

- Linear：使用 `.05–.08` 白色边框和 6px 功能控件圆角。
- Linear：浮层采用多层低透明阴影，替换为冷蓝染色。
- Warp：使用 `#faf9f6` 暖白文字与 `.04` 白色表面层。
- Warp：业务区保持平面，只有真实窗口和浮层拥有深度。

## 工艺密度

原创 SVG 山脊壁纸、品牌 selection、品牌 focus 环、窗口吸附与平铺签名交互、冷色多层窗口阴影、自定义滚动条、统一 SVG 图标、活动窗口内高光。

## 数据边界

16 条 2026-11-25 公开快照；主题、收藏与壁纸仅 localStorage；无生产 API 请求、账户或虚假系统监控。Kitty 主题原始配置与 MIT 许可证保存在 `references/`，来源记录见 `THIRD_PARTY_NOTICES.md`。


## 两轮实渲染记录

第一轮：1440px 与 375px 截图确认首屏桌面、独立窗口和启动层移除；艺术评审指出手绘图标与双层边框缺少真实系统来源，读者评审指出应用列表文字偏小，工程评审随后发现 FLIP 非等比缩放扭曲中文。

第二轮：接入 Papirus 原图标与 Rofi 无边框参考，活动窗口改为单层 2px 边框；提高列表字号；动画删除 scaleX/scaleY，仅保留位置补偿。真实鼠标验证拖拽、最小化恢复、工作区、平铺和移动端；真实系统键盘验证终端提交，并修复首次挂载欢迎记录未渲染的问题。

最终 UI 检查：Papirus 图标全部加载，动画结束后 transform 归零，桌面和 375px 视口无页面横向溢出，浏览器运行时错误为 0。

## 双主题与纯终端迭代

Afterglow 与 Atelier Sulphurpool 均使用上游 Kitty 原始色值；系统表面与终端 ANSI token 分离，默认主题为 Afterglow。主题可从外观窗口、Rofi 或 `theme` 命令切换并持久化。

终端取消欢迎卡片、会话条和窗口状态栏，`fetch` 信息、命令回显与输入提示符共享一个滚动文本流；新增 `fetch`、`theme`、`history` 和上下方向键历史。窗口管理、壁纸、赛事功能与数据快照未改。

本轮按用户要求不执行浏览器自动化或截图验收；视觉对比由用户亲自完成。交付前仅进行代码通读、JavaScript 语法检查、资源与结构静态检查和仓库测试，不将此前交互验收当成本轮视觉认可。

## 微文案与滚动修正

所有应用移除重复窗口状态栏；外观页移除工具栏、壁纸描述、分类、操作提示和主题副标题；通知中心与 Rofi 移除装饰性及操作说明页脚。保留赛事名称、分类、主办方、节点、来源、空态恢复等实质信息，详情来源说明收敛为一行。

外观窗口由 `.window-body` 建立纵向 flex 高度链，`.wallpaper-app` 使用 `flex: 1; min-height: 0`，侧栏以 `min-height: 0; overflow-y: auto; overscroll-behavior: contain` 独立滚动，不再把工具栏高度与 100% 内容高度叠加。移动端改为单一滚动区域，避免嵌套滚轮。

本轮继续遵守用户要求，不执行浏览器自动化；滚轮与视觉结果由用户验收。

## 交互完善与回归证据

## 留言板、推送与文档应用

三个功能注册为独立 OS 应用，通过 Rofi、终端 `open` 和通知中心进入，不增加桌面图标或永久业务侧栏。留言板使用分隔线式评论流与单区编辑器；文档使用 148px 目录、独立文章滚动区、暗色表格和代码块；推送使用系统开关与订阅动作，全部继承双主题 token，窄屏目录改为横向切换。

留言板沿用 `/api/v1/me` 与 `/api/v1/comments` 契约，生产同源环境可读取、登录和发言。静态预览不伪造 GitHub 会话或用户讨论；2026-11-25 线上公开留言接口返回空数组，因此展示真实空态和线上入口。评论内容继续转义，作者链接仅允许 HTTPS。

推送明确区分页面内浏览器通知与生产 ICS 日历订阅。通知权限只在用户点击后请求，偏好持久化，刷新及收藏变化会重排提醒；没有 Service Worker 或服务端 Web Push，界面明确标注“页面打开时有效”。文档采用真实 API 路径、1000 字与频率限制、Asia/Shanghai 和官网核实口径，终端 `man api|data|comments|ics` 可直接定位。

新增 4 项回归在实现前失败、实现后通过；目标回归共 16 项，覆盖应用注册、本地 Papirus 图标、留言空态与转义、推送边界、文档接口和 `man` 命令。完整仓库测试 46/46 通过，JavaScript 语法与静态资源检查通过。未进行浏览器自动化，权限弹窗、真实留言和日历应用跳转需由用户决定并验收。

## 原生窗口与应用结构修正

用户验收指出第一版仅换色，窗口和应用没有实质差异。本轮不再以 token 替换充当主题实现：窗口背景由近乎不透明改为分层半透明，标题栏缩至 30px 并隐藏彩色应用图标；赛事新增 `~/contests` 位置栏，目录侧栏与列表改成文件管理器式平面结构；按钮、搜索、文档目录、留言编辑器和推送控件统一为低高度原生控件。时间线节点由圆点改为刻度线。

fastfetch 改成 Software / Contestline 双框线面板、底部快照信息和方形 ANSI 色板，切换主题时立即重建终端输出。未加入虚假 CPU、GPU、内存、uptime 或媒体信息，原壁纸保持不变。

随后三套主题统一继承透明窗口、紧凑标题栏、原生应用表面、位置栏与框线 fastfetch，共享选择器使用 `:root[data-theme]`，色彩仍由各自 token 决定。Wallhaven 应用表面进一步改为中性炭灰，选中底降至 9–10%，玫瑰色只保留少量焦点；Wallhaven 终端的字体、框线、Kitty 前景与 ANSI 色板不变。Afterglow 和 Atelier 使用各自的窗口活动色、终端字体和 Kitty 色板。
